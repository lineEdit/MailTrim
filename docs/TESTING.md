# Проверка выпуска

Автоматические проверки:

```powershell
dotnet run --project tests/MailTrim.Tests -c Release
dotnet run --project tests/MailTrim.Smoke -c Release -- C:\path\to\empty-test-directory
```

Smoke требует установленный WebView2 Runtime и Windows-сеанс. Создаёт только новые тестовые профили по указанному пути, не использует реальные ящики. Проверяет настоящее внедрение CSS, отсутствие CSS на узле входа, изоляцию cookies, очистку сессии, отключение native bridge, сетевую блокировку, приостановку фильтров и безопасный формат журнала. Фикстуры подменяются локально через WebView2, без отправки тестовых писем. При инициализации возможен запрос к официальной странице входа из пустого профиля.

## Ручная проверка с пользователем перед стабильным релизом

Регрессия 0.1.1: фикстура `Fixtures/mail-ads.html` проверяет верхний баннер, рекламную строку, карточку с меткой рекламы, позднюю вставку, виртуализированную строку и восстановление CSS. Обычная рассылка с меткой «Реклама 18+» в теме, тело письма и редактор остаются видимыми. Это синтетическая фикстура, а не выгрузка личной почты. Проверяются также миграция стандартных правил и сохранение пользовательского набора.

Регрессия 0.1.3: добавлены вложенные DIV-метки, карточка без ссылок, правая колонка `.noads-button`, возврат ширины списку писем и защита почтовой ссылки `.js-letter-list-item`. Во время исправления локально проверялись классы, геометрия и счётчики текущей веб-страницы; содержимое писем и персональные ссылки не сохранялись и в репозиторий не включались. CI работает только на обезличенных фикстурах.

- Вход Mail.ru, 2FA и используемый вами сценарий VK ID; закрытие окна входа и отмена.
- Второй ящик, переключение, перезапуск и сохранение обеих сессий.
- Входящие, отправленные, поиск, папки, длинная цепочка писем.
- Черновик, редактирование, отправка тестового письма себе (только явное действие пользователя).
- Выбор вложения, скачивание и отмена скачивания, печать через интерфейс сайта.
- Внешняя ссылка и target=_blank: системный браузер, без навигации оболочки наружу.
- Сравнение фильтров включено/выключено: реклама, промо, новости, рекомендации; убедиться, что письма и редактор не скрыты.
- Светлая/тёмная темы, системный масштаб 100/150/200%, клавиатура.
- Потеря сети, возврат сети, перезапуск приложения.
- Очистка сессии одного профиля не затрагивает другой.

Список не считается пройденным автоматически. Проверка на личном авторизованном ящике требует пользователя и не заменяется тестовыми HTML-страницами.
