# Тестирование

## Полная проверка

На Windows с WebView2 Evergreen Runtime:

```powershell
./scripts/Check.ps1
```

Скрипт восстанавливает зависимости с `--locked-mode`, собирает Release и запускает три набора. Для уже собранного решения есть `-NoBuild`; `-ScratchRoot` задаёт новый тестовый каталог. Существующие каталоги не перезаписываются, результаты не удаляются автоматически.

| Проект | Область проверки |
| --- | --- |
| MailTrim.Tests | Правила, навигация, очистка данных, даты, счётчики, каталог релизов, сжатые ответы и пакеты |
| MailTrim.UpdateTests | Передача запуска, подтверждение готовности, ошибки, таймаут и возврат предыдущей версии |
| MailTrim.Smoke | WPF/WebView2, изоляция сессий, CSS и сетевые фильтры, парсер, очередь, кэш и интерфейс |

Тесты используют изолированные каталоги и синтетические HTML-фикстуры. Smoke подменяет страницы через WebView2, не читает личную почту и не отправляет письма. При инициализации пустого профиля возможен запрос к официальной странице входа. UpdateTests запускает служебные процессы из тестового каталога.

Отдельные наборы после сборки:

```powershell
dotnet run --project tests/MailTrim.Tests -c Release --no-build
dotnet run --project tests/MailTrim.UpdateTests -c Release --no-build -- C:\Temp\mailtrim-updates-unique
dotnet run --project tests/MailTrim.Smoke -c Release --no-build -- C:\Temp\mailtrim-webview-unique
```

Пути должны быть новыми. Для Smoke также требуется интерактивный Windows-сеанс.

## Проверка дистрибутива

После упаковки проверяются ZIP, SHA-256, распаковка, версия сборки и запуск настоящего EXE. Тестовый проект и пакет должны иметь одну версию. Подставьте актуальную версию из `Directory.Build.props` и новый каталог:

```powershell
dotnet run --project tests/MailTrim.UpdateTests -c Release --no-build -- --verify-package artifacts/MailTrim-0.12.9-win-x64.zip C:\Temp\mailtrim-package-unique
```

Повторите команду для `MailTrim-0.12.9-win-x64-lite.zip` с другой новой тестовой папкой. CI проверяет оба пакета и соответствие встроенного типа сборки её требованиям к .NET. EXE запускается с `--verify-package-launch` в новой папке и проверяет ресурсы WPF и загрузчик WebView2 на локальной странице. Режим включается до обращения к обычным настройкам, сессиям, перенаправлению обновления и блокировке второго экземпляра. Запросы тестовой страницы подменяются локально; личная почта не используется. Ошибка или зависание завершают проверку неуспешно. Рабочий вход и авторизованную почту проверяет пользователь отдельно.

## Фикстуры фильтрации

`tests/MailTrim.Smoke/Fixtures/` содержит обезличенные примеры баннеров, рекламных строк, правой колонки, промо-диалогов и поздних вставок. Обычное письмо со словом «Реклама» в теме, тело письма и редактор должны оставаться видимыми.

Фикстура запуска проверяет раннее внедрение очистки и отсутствие видимой рекламы до загрузки скриптов страницы. Проверяются также отключение фильтров, отсутствие CSS на странице входа и миграция стандартных правил. Это известные примеры разметки, а не гарантия для всех будущих страниц Mail.ru.

## Ручная проверка перед стабильным выпуском

- Вход Mail.ru, 2FA и VK ID; новое окно входа, отмена и закрытие.
- Второй ящик, переключение, сохранение режима чтения и сессий после перезапуска.
- Входящие, отправленные, поиск, папки и длинная цепочка.
- Чтение текста, картинки по нажатию, сортировка дат, поиск в кэше и обновление заголовков.
- Загрузка доступных папок: прогресс, отмена, частичный результат и сохранение кэша.
- Ответ в официальном редакторе рядом со списком; защита несохранённого ответа.
- Черновик, редактирование и отправка тестового письма себе — только явное действие пользователя.
- Вложения, скачивание и отмена; печать через интерфейс сайта.
- Внешняя ссылка с подтверждением и корректное окно официального входа.
- Фильтры включено/выключено: реклама скрыта, письмо и редактор остаются.
- Темы, масштаб Windows 100/150/200%, клавиатура и размеры окна.
- Трей, полный выход, автозапуск, исходный счётчик без уведомления и новое письмо с уведомлением.
- Потеря и возврат сети; неизвестный счётчик не становится достоверным нулём.
- Очистка одного профиля не затрагивает другой.
- Установка обновления; сохранение профилей и возврат при неудачном запуске.

Этот список не считается пройденным автоматически. Авторизованную почту проверяет пользователь; фиксируйте выполненные сценарии и ограничения в описании выпуска.
