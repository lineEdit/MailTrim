# Руководство пользователя

[Главная страница](../README.md) · [Безопасность](../SECURITY.md) · [Правила](RULES.md)

## Выбор выпуска

Обычный архив `MailTrim-<версия>-win-x64.zip` содержит .NET. Облегчённый `MailTrim-<версия>-win-x64-lite.zip` требует отдельно установленного [.NET 10 Desktop Runtime x64](https://dotnet.microsoft.com/en-us/download/dotnet/10.0); обычного .NET Runtime или ASP.NET Runtime недостаточно. Оба требуют Windows 10/11 x64 и WebView2 Runtime и имеют одинаковые функции.

Запускайте `MailTrim.exe` из полностью распакованной папки. Встроенные обновления сохраняют выбранный выпуск. Для ручного перехода между ними завершите прежнюю копию через трей и распакуйте другой архив в новую папку; ящики, настройки и кэш сохраняются.

## Аккаунты и официальный вход

После распаковки запускайте `MailTrim.exe` из корня папки. Других запускаемых файлов в дистрибутиве нет. Два небольших служебных файла рядом с ним нужны для обновлений; оставьте их на месте. Документация находится в `docs`, лицензии — в `licenses`, встроенные правила — в `rules`.

Добавляйте ящики кнопкой **+** или через **⋯ → Добавить ящик**. Каждый профиль имеет отдельное хранилище WebView2. Авторизация, VK ID, 2FA и восстановление доступа выполняются страницами сайта; MailTrim не сохраняет пароли и не вводит их за вас.

Переключение вкладок сохраняет активный режим и позицию чтения отдельно для каждого профиля в текущем запуске. Переименование меняет локальное название, а не адрес ящика. Очистка сессии удаляет локальные браузерные данные и кэш чтения; удаление профиля не удаляет серверный ящик.

Внешние HTTP(S)-ссылки открываются в системном браузере после подтверждения домена. Вложения сохраняются через выбор файла и автоматически не запускаются.

## Фильтрация и оформление

В настройках можно отдельно включать блокировку запросов, косметические фильтры и дополнительные селекторы. **Фильтры: вкл** временно приостанавливает фильтрацию. Перед перезагрузкой сохраните черновик.

CSS устанавливается в начале создания документа. Первая очистка проходит под кратким скрытием веб-почты, чтобы баннеры не появлялись до применения правил; предусмотрено снятие защиты по таймеру через 1,5 секунды. Страницы входа и пауза фильтров не скрываются. Неизвестные рекламные блоки могут потребовать новых правил.

Файл правил: `%LOCALAPPDATA%\MailTrim\rules.json`. Его можно импортировать и редактировать в **Настройки → Правила**. После внешнего редактирования нажмите **Прочитать локальный файл**, затем **Сохранить и перезагрузить**. JSON не содержит исполняемого JavaScript. [Формат правил](RULES.md).

Оболочка поддерживает светлую, тёмную и системную темы. Mail.ru получает предпочтение цвета, но может использовать собственную настройку темы. Размер, положение и развёрнутое состояние окна сохраняются; при отключении монитора Windows возвращает окно в доступную область.

## Режим «Только важное»

Откройте нужный ящик и нажмите **Только важное**. Слева находятся папки и список сообщений, справа — текст выбранного письма. Название означает упрощённый вид, а не автоматический отбор важных писем или удаление рассылок.

Источник — официальная страница Mail.ru в скрытом WebView2. В собственную панель передаются очищенные текстовые блоки и HTTPS-ссылки на картинки; HTML, формы и скрипты письма там не выполняются. Письма идут от новых к старым. Используются дата сайта и время извлечения, а не время записи файла кэша. Старые записи без достоверного дня отмечены **дата не уточнена** и идут в конце.

Сохранённый список показывается предварительно. После получения данных сайта он заменяется актуальными строками выбранной папки. Папки доступны одним нажатием в левой панели: стандартные и найденные на странице пользовательские папки с их названиями. Текущая папка выделена и указана над сообщениями. **☰** сворачивает или показывает панель; настройка сохраняется между запусками. Кнопка остаётся на одном месте: при сворачивании остаётся узкая полоса шириной 40 пикселей, а остальная ширина освобождается для чтения. Ширина списка писем сохраняется.

При быстром переключении загрузка предыдущей папки отменяется. Локальный поиск сбрасывается, чтобы не показывать результаты другой папки. Во время ответа или выполняемой операции папку сменить нельзя. После переключения аккаунтов и возврата в режим восстанавливается выбранная папка. Изменения уже открытого списка читаются раз в две секунды, а сама папка проверяется раз в минуту, когда приложение не занято чтением или ответом.

Письма заранее преобразуются в готовые очищенные структуры для собственного интерфейса. Сохранённые документы подготавливаются из зашифрованных файлов в фоне, без открытия сайта. Память отдельна для каждого ящика и ограничена 80 документами и четырьмя миллионами символов. Структуры сохраняются при переключении аккаунтов; после перезапуска подготавливаются снова из файлов.

Для свежих данных приложение последовательно открывает в скрытой официальной странице до 20 последних **подтверждённо прочитанных** писем текущей папки. Непрочитанные и письма без надёжного признака прочтения автоматически не открываются. Отсутствие отметки «непрочитано» само по себе не считается подтверждением прочтения. Показатель **Готово к чтению** отражает документы в памяти; подготовка не означает полный обход ящика. Фоновая страница может загружать картинки, даже если в собственной панели они ещё не показаны.

Недавно проверенное готовое письмо показывается сразу, без новой навигации. Через пять минут, при изменении заголовка или предварительного текста и после ручного **↻** данные требуют повторной проверки: имеющийся текст остаётся предварительным просмотром, а свежий результат заменяет его. Если сайт недоступен, остаётся явно обозначенная сохранённая копия. Неизменённое письмо во время проверки сохраняет загруженные картинки и положение чтения. Первое явное открытие непрочитанного письма может отметить его прочитанным на сайте.

Выбор сообщения, смена папки, ответ и поиск имеют приоритет над подготовкой. Долгое фоновое чтение ограничено восемью секундами; ошибка повторяется не раньше чем через минуту. Очистка кэша удаляет готовые структуры и закрывает активную собственную панель чтения. При повторном входе документы могут подготавливаться снова; массовый фоновый обход после очистки остаётся на паузе.

Кнопка **↻** получает новый снимок текущей папки, сохраняя отображаемое письмо. **+** подгружает доступные строки этой папки прокруткой сайта. Список ограничен строками, доступными через веб-интерфейс; автоматически полученные страницы не подтверждают полную синхронизацию ящика и серверных удалений. Другие сохранённые папки доступны через локальный поиск и резерв при отсутствии связи.

Чтение получает приоритет над фоновой проверкой. Поиск откладывает её до сброса поисковой строки; ответ, загрузка всего кэша и выход из режима отменяют проверку. Ошибка сети или отсутствие входа не удаляют сохранённые письма.

Границу между списком и письмом можно перетаскивать. Ширина 260–520 точек сохраняется между запусками; двойной щелчок возвращает 310 точек. Доступны Tab и стрелки для управления разделителем.

### Картинки и вложения

Картинки загружаются отдельным нажатием без cookies, максимум 8 МБ. Отправитель может узнать о просмотре. Недоступные или требующие авторизации изображения открывайте в оригинале.

Официальная фоновая страница может сама загружать изображения: это не полная защита от пикселей отслеживания. Вложения пока не перечисляются в собственной панели. Для скачивания, сложных таблиц, ссылок и печати используйте **Оригинал / вложения ↗**.

### Ответ и другие действия

Кнопки **Ответить**, **Прочитано**, **В архив** и **Удалить…** работают через распознанные элементы официального интерфейса. Нажатие не считается подтверждением серверной операции. Если кнопка не распознана или сайт требует подтверждения, проверьте результат в оригинале. Постоянное удаление из корзины и операции в нестандартных папках выполняются вручную.

**Ответить** открывает официальный Mail.ru в правой панели рядом со списком. Если редактор не появился, нажмите кнопку ответа на сайте. Проверьте получателя, текст и вложения; приложение никогда не нажимает **Отправить**.

Пока ответ открыт, выбор другого письма и поиск заблокированы. Можно переключиться на другой аккаунт и вернуться без перезагрузки редактора. **← К чтению** возвращает собственное представление; сначала отправьте письмо или сохраните черновик в Mail.ru.

Кнопки приложения **Назад**, **Обновить**, **Входящие** и полный выход предупреждают об открытых панелях ответа. Отказ сохраняет редактор. Проверка не определяет, сохранён ли текст сервером, и не контролирует навигацию внутри сайта, выключение Windows или принудительное завершение процесса.

## Локальный поиск

Введите текст над списком и нажмите **Enter** или **Найти**. Поиск без учёта регистра проверяет отправителя, тему, превью и сохранённый текст текущего профиля. Заголовки новых писем ищутся до загрузки тела; полный текст доступен после чтения или предварительной загрузки.

Поиск работает без сетевых запросов, вне потока интерфейса. Он не охватывает содержимое вложений и несохранённый текст серверного ящика. Сброс — **×** или **Esc**. Обновление списка и загрузка кэша сбрасывают поиск; строка поиска не сохраняется после выхода из режима.

## Кэш всего ящика

В **Настройки → Письма и кэш** включите **Автоматически кэшировать прочитанные письма во всех папках** и сохраните. По умолчанию настройка выключена. После включения фоновый обход начнётся сразу; при следующих запусках — примерно через 15 секунд. Для каждого профиля создаётся отдельная скрытая страница официального сайта: она не переключает открытое письмо или редактор ответа. Ящики обрабатываются последовательно; повторная проверка — через 15 минут после завершения, после ошибки — через две минуты. Приложение продолжает загрузку в трее, пока запущено.

Сначала обходятся доступные стандартные и найденные пользовательские папки. В это время общий объём неизвестен: показываются обработанные/найденные папки и число найденных писем. После поиска полоска прогресса и счётчик показывают обработанные и оставшиеся **найденные прочитанные** письма, сохранённые документы и ошибки. Заголовки непрочитанных, неизвестных по статусу и черновиков сохраняются, но их тела автоматически не открываются. Пропущенные письма не входят в остаток загрузки. Уже сохранённые тела повторно не скачиваются. Это не гарантия полноты ящика: сайт может не показать часть папок или строк; неподтверждённые концы списков отмечаются в результате.

В этой же вкладке можно выбрать ящик и посмотреть его прогресс, **Приостановить** загрузку либо **Проверить и продолжить**. Пауза действует до возобновления или следующего запуска. Остановка сохраняет уже загруженные данные; следующий обход дополняет их. После очистки локального кэша загрузка приостанавливается, чтобы он не заполнился снова сразу. Письма на сервере остаются. Кнопка **Кэш…** над списком открывает эту вкладку настроек.

Текст, заголовки и ссылки на картинки сохраняются между запусками в `%LOCALAPPDATA%\MailTrim\ReaderCache\<профиль>` с Windows DPAPI CurrentUser и дополнительной привязкой к профилю. Имена файлов не содержат открытых почтовых URL. Картинки и вложения массово не сохраняются в кэш; скрытая официальная страница может загружать изображения. Лимит — 512 МБ на профиль, индекс заголовков также ограничен размером и числом записей.

Во время автоматического обхода список и чтение остаются доступны. Выход из режима чтения не останавливает отдельный фоновый источник; полностью завершить загрузку можно паузой в настройках или выходом из приложения.

Скрытые папки, виртуализация, изменённая разметка и ограничения сайта могут препятствовать полному обходу. Кэш ускоряет чтение, но **не является гарантированной резервной копией ящика**. Не удаляйте оригиналы на основании отчёта. Удаления на сервере автоматически не удаляют локальные копии; кэш можно очистить в **Настройки → Письма и кэш → Очистить кэш выбранного ящика**. [Подробнее о приватности](../SECURITY.md).

## Трей, автозапуск и уведомления

В **Настройки → Windows и уведомления** доступны автозапуск, закрытие в трей и уведомления. Автозапуск изначально выключен; запись HKCU Run запускает текущий EXE с `--tray`, без прав администратора. После ручного переноса приложения заново сохраните настройку.

Крестик по умолчанию скрывает окно, сохраняя процесс и сессии. Значок находится рядом с часами, иногда под стрелкой скрытых значков. Двойной щелчок открывает окно; меню **Выйти** завершает процесс. Повторный запуск показывает уже работающее окно.

### Счётчики и обычная проверка

Первая проверка начинается приблизительно через 15 секунд, последующие — раз в две минуты. Отдельное скрытое окно с той же сессией проверяет доступный список входящих без открытия писем. Аккаунты проверяются последовательно, поэтому при медленной сети цикл может быть длиннее. В меню трея есть **Проверить почту сейчас**.

На вкладках показано доступное число непрочитанных **во входящих**, а в подсказке и строке состояния — результат и время проверки. Нет показателя сайта — нет выдуманного нуля. В трее синий значок с числом до **99+** означает известную сумму; серый **M** — подтверждённый ноль либо недоступный счётчик. Состояние может отставать от действий на сайте.

Первая успешная проверка задаёт исходную точку: старые письма не объявляются новыми. Оповещения содержат только количество, без адресов и текста. Это проверка доступного списка, а не гарантированная доставка всех событий. Windows может подавлять уведомления режимом **Не беспокоить**.

### Уведомления сайта

Можно выбрать **Использовать уведомления сайта Mail.ru вместо опроса**. Включите уведомления в самой почте при необходимости, обновите страницу и откройте вкладки нужных аккаунтов. WebView2 показывает уведомления только от HTTPS e.mail.ru; они могут содержать отправителя и тему, переданные сайтом.

В этом режиме оповещения по опросу выключены, но проверка состояния аккаунтов продолжается. Общий переключатель уведомлений в трее отключает оба способа. Доставка зависит от сайта, сети, сессии и настроек Windows; полностью закрытое приложение ничего не получает. Уведомления сайта не являются счётчиком непрочитанных.

## Обновления

В настройках или меню трея нажмите **Проверить обновление**. Проверка при запуске изначально выключена. Для текущих предварительных выпусков переключатель **Включать предварительные версии** включён по умолчанию; черновики никогда не предлагаются. Без этого переключателя используется стабильный канал GitHub.

Из официального `lineEdit/MailTrim` доступны **Скачать и установить**, проверка ZIP, SHA-256 и версии. Для другого репозитория открывается точная страница выпуска. Перезапуск требует подтверждения: сначала сохраните черновики. Загрузка отменяется кнопкой; установка не требует прав администратора.

Новая версия размещается в `%LOCALAPPDATA%\MailTrim\Updates`, отдельно от профилей и кэша. Если запуск не подтверждён за 60 секунд, запускается предыдущая версия. Существующие ярлыки современных версий перенаправляются на установленное обновление; автозапуск перенастраивается при запуске. Старые пакеты пока не удаляются автоматически.

SHA-256 проверяет целостность архива, но не заменяет цифровую подпись издателя. При сетевой ошибке можно открыть страницу релизов вручную.

## Сочетания клавиш

При фокусе в интерфейсе приложения или режиме чтения:

| Клавиши | Действие |
| --- | --- |
| Ctrl+F | Поиск в сохранённых письмах |
| Esc | Сброс поиска |
| Ctrl+Tab / Ctrl+Shift+Tab | Следующий / предыдущий ящик |
| F5 | Обновление с защитой открытого ответа |

В оригинальной веб-странице сочетания может обрабатывать Mail.ru или WebView2. Во время загрузки некоторые команды временно недоступны.
