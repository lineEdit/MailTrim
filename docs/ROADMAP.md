# Направления развития

Это предложения для следующих итераций, а не уже реализованные возможности или обещание сроков. Текущее поведение описано в [руководстве пользователя](USER-GUIDE.md).

## Ближайший приоритет — надёжность чтения

- Периодическое обновление собственного списка, пока открыт режим чтения, с сохранением выбора, прокрутки и поиска.
- Явный статус свежести данных: когда список обновлялся, что есть в кэше и что ещё загружается.
- Признак непрочитанного у каждого извлечённого письма; отдельный фильтр непрочитанных с проверкой актуальности на сайте.
- Единая понятная сортировка по времени, объяснение писем без распознанной даты и обработка изменений разметки.
- Дополнительные обезличенные фикстуры для новых вариантов Mail.ru и проверки отсутствия промаргивания.

## Следующий этап — удобство

- Папки в собственном режиме чтения, без перехода к полному интерфейсу сайта.
- Список вложений с безопасным скачиванием и понятным переходом к оригиналу.
- Управление кэшем: размер по профилям, прогресс, отмена, повтор ошибок и очистка отдельно от выхода из аккаунта.
- Выбор компактности интерфейса и улучшения управления с клавиатуры.

## Подготовка к стабильным выпускам

- Подпись Windows-дистрибутива и проверка установки на чистой Windows.
- Дальнейшая проверка обновления, отката и сохранения несохранённого ответа на реальных сценариях.
- Настройка источника правил с проверкой формата и подтверждением применения, без загрузки удалённого JavaScript.
- Диагностика состояния парсера без выгрузки писем, адресов и токенов.

Полную синхронизацию, резервную копию ящика и достоверный счётчик нельзя обещать по неполной странице. Такие функции требуют отдельного решения с проверяемым источником данных; парсер официального интерфейса остаётся зависимым от сайта.
