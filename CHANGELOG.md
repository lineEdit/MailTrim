# Changelog

## 0.1.1 — 2026-09-30

- Добавлены фильтры верхних баннеров и рекламных строк Mail.ru, рекламного прокси на домене почты.
- Короткие метки рекламы проверяются внутри рекламных карточек; реальные почтовые ссылки, тело письма и редактор исключены из эвристики.
- Обработаны динамическая вставка рекламы, восстановление удалённых стилей и повторное использование рекламной строки для настоящего письма.
- Неизменённый стандартный набор 0.1.0 обновляется автоматически с резервной копией; пользовательские наборы сохраняются.
- Добавлены регрессионные проверки на синтетических страницах. Точное совпадение с DOM пользовательского скриншота пока не проверено на авторизованной почте.

## 0.1.0 — 2026-09-30

Первый предварительный выпуск: WPF/WebView2, изолированные профили, фильтрация запросов, декларативные CSS-правила с JS-вставкой, темы, управление сессиями, проверка GitHub-релизов и Windows CI.

Ограничения: без автоматической установки обновлений и подписанного установщика; начальные селекторы требуют проверки на авторизованной почте. Поддержка дополнительных сценариев SSO может потребовать расширения точного списка доверенных узлов после проверки.
