# Безопасность и приватность

MailTrim использует официальный веб-интерфейс. Нет собственного поля пароля, перехвата паролей, IMAP/SMTP, обхода 2FA или экспорта cookies.

## Сессии и локальные данные

Каждый профиль имеет GUID и отдельную папку WebView2 в `%LOCALAPPDATA%\MailTrim\Profiles`. Корневая папка получает Windows ACL для текущего пользователя, SYSTEM и администраторов.

Cookies и данные сайтов управляются WebView2. **Не всё содержимое браузерного профиля зашифровано:** кэш и данные сайта могут содержать письма. Изоляция не защищает от программ того же пользователя Windows или администратора. Парольный менеджер и автозаполнение WebView2 отключены.

Отдельный кэш чтения сохраняет текст, заголовки и ссылки на картинки через DPAPI CurrentUser с привязкой к GUID профиля. Имена файлов — SHA-256 URL, запись атомарная через зашифрованный временный файл. Кэш не синхронизирует все серверные удаления и не является полной резервной копией.

Очистка сессии удаляет браузерные данные через `ClearBrowsingDataAsync(AllProfile)` и кэш чтения. Пустая папка может остаться. Это не гарантированное стирание диска, не отзыв серверных токенов и не удаление писем.

## Навигация и содержимое

Host objects, web messages и DevTools отключены. Sandbox и проверка сертификатов не отключаются.

Верхний документ ограничен HTTPS и точным списком узлов в `NavigationPolicy`. Внешние переходы пользователя требуют подтверждения, фоновые внешние редиректы останавливаются. Произвольные протоколы, локальные файлы и URL с userinfo не запускаются оболочкой. Подресурсы и фреймы остаются под контролем браузерной same-origin policy с фильтром рекламных доменов; список верхних страниц не является firewall для всех запросов.

Косметический JS работает только на `https://e.mail.ru` в главном фрейме. Он применяет CSS и обрабатывает рекламные метки, защищая известные контейнеры письма, редактора и почтовые ссылки. JSON принимает селекторы, а не удалённый JS или CSS-декларации. Неправильные правила могут скрыть полезные элементы.

Собственное представление строится из ограниченных очищенных моделей. HTML письма и его скрипты в нём не исполняются. Картинки загружаются по нажатию без cookies браузерной сессии, но сайт-источник продолжает работать в WebView2: режим чтения не гарантирует отключения всех трекеров. Открытие письма на сайте может отметить его прочитанным.

## Журнал и уведомления

Журнал приложения не содержит cookies, заголовков и тел запросов, писем, названий профилей, адресов или полных URL. Браузерные данные хранятся отдельно.

Отдельная настройка разрешает браузерные уведомления только от HTTPS `e.mail.ru`. Они могут содержать отправителя и тему и отображаются средствами WebView2/Windows; приложение их не журналирует. Служебные окна опроса подавляют такие уведомления. Уведомления могут быть видны другим людям на экране пользователя.

## Обновления

Проверка обращается к GitHub по действию пользователя или при включённой настройке. Она не устанавливает релиз сама. Загрузка, распаковка и запуск происходят после подтверждения пользователем.

Проверяются допустимые адреса, SHA-256, структура ZIP и версия. Новая копия устанавливается отдельно, неудачный запуск вызывает возврат предыдущей версии. SHA-256 проверяет целостность относительно опубликованной суммы и не заменяет подпись издателя. Дистрибутив пока не подписан Authenticode.

Правила обновляются импортом JSON или выбором встроенного набора, без исполнения недоверенного удалённого скрипта.

## Сообщение о проблеме

Не запускайте приложение от администратора. Не отправляйте Profiles или ReaderCache, письма, токены и персональные URL. Для отчёта достаточно версии приложения, Windows/WebView2, шагов воспроизведения и обезличенного `events.log`.

Для уязвимостей используйте private vulnerability reporting репозитория, если оно включено. Не публикуйте секреты или подробности личной сессии в публичном issue.

Основание решений: [WebView2 security](https://learn.microsoft.com/microsoft-edge/webview2/concepts/security) и [user data folders](https://learn.microsoft.com/microsoft-edge/webview2/concepts/user-data-folder).
