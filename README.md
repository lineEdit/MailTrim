# MailTrim

[![Windows pipeline](https://github.com/lineEdit/MailTrim/actions/workflows/windows.yml/badge.svg)](https://github.com/lineEdit/MailTrim/actions/workflows/windows.yml)

Windows-приложение для официальной веб-почты Mail.ru: изолированные аккаунты, фильтрация рекламы и собственный режим чтения текста и картинок. C# · .NET 10 · WPF · WebView2.

Проект находится в стадии предварительных выпусков. [Скачать релиз](https://github.com/lineEdit/MailTrim/releases) · [История изменений](CHANGELOG.md) · [Версия сборки](Directory.Build.props).

MailTrim не связан с Mail.ru или VK. Он использует штатный веб-вход, без IMAP/SMTP, собственных форм пароля и обхода авторизации.

## Быстрый старт

1. Требуются Windows 10/11 x64 и [WebView2 Evergreen Runtime](https://developer.microsoft.com/microsoft-edge/webview2/).
2. Выберите Windows x64 ZIP со [страницы релизов](https://github.com/lineEdit/MailTrim/releases): обычный содержит .NET, а **Lite** требует установленного **[.NET 10 Desktop Runtime x64](https://dotnet.microsoft.com/en-us/download/dotnet/10.0)**. Распакуйте **весь выбранный архив** в отдельную папку.
3. Запустите `MailTrim.exe` и войдите на официальной странице Mail.ru или VK ID.
4. Добавьте другой ящик кнопкой **+** или через **⋯ → Добавить ящик**. Аккаунты переключаются вкладками сверху.
5. Нажмите **Только важное** для собственного представления письма. Режим упрощает оформление, а не определяет важность писем.

Закрытие крестиком по умолчанию сворачивает приложение в трей. Полный выход — через меню значка рядом с часами. Обновления проверяются в настройках и меню трея.

В дистрибутиве один запускаемый файл — `MailTrim.exe`; библиотеки включены в него. Документация и лицензии находятся в папках. `MailTrim.dll` и `MailTrim.runtimeconfig.json` сохранены для совместимости со старым механизмом обновлений: их не нужно запускать или удалять.

| Выпуск | Архив | Что устанавливать отдельно |
| --- | --- | --- |
| Обычный | `MailTrim-<версия>-win-x64.zip` | WebView2 Runtime |
| Lite | `MailTrim-<версия>-win-x64-lite.zip` | .NET 10 Desktop Runtime x64 и WebView2 Runtime |

Функции одинаковые. Обновление из приложения сохраняет выбранный выпуск; для ручного перехода распакуйте другой архив в новую папку и полностью завершите прежнюю копию через трей. Ящики, настройки и кэш общие для обоих выпусков.

Дистрибутив пока не подписан Authenticode. [Безопасность и приватность](SECURITY.md).

## Что умеет приложение

- Отдельные браузерные сессии для нескольких ящиков; официальный вход и окна VK ID.
- Блокировка рекламных запросов, CSS-фильтры и очистка промо; локальное редактирование и импорт JSON-правил.
- Режим чтения без интерфейса сайта: текст, картинки по нажатию, поиск в локальном кэше и ответ в официальной странице рядом со списком.
- Зашифрованный кэш с сохранением между запусками. При входе в режим чтения заголовки входящих обновляются в фоне; доступные папки можно загрузить отдельной командой.
- Автозапуск, трей, уведомления и доступные счётчики непрочитанных во входящих.
- Светлая, тёмная и системная темы, сохранение положения окна и ширины списка.
- Проверка GitHub-релизов, подтверждаемая установка обновления и возврат к предыдущей версии при неудачном запуске.

## Ограничения

Фильтры и парсер зависят от разметки Mail.ru. Полное удаление рекламы, полный обход ящика и точный счётчик при отсутствии данных сайта не гарантируются. Режим чтения пока экспериментальный; вложения и сложное оформление доступны в оригинале.

Открытие письма на сайте может отметить его прочитанным. Локальный кэш не синхронизирует серверные удаления и не является резервной копией всего ящика. Cookies управляются WebView2; не всё содержимое его браузерного профиля зашифровано. Подробности — в [руководстве пользователя](docs/USER-GUIDE.md) и [модели безопасности](SECURITY.md).

## Для разработчиков

Требуются Windows, .NET 10 SDK и WebView2 Runtime. Параметры SDK заданы в [global.json](global.json).

```powershell
dotnet restore MailTrim.sln --locked-mode
dotnet build MailTrim.sln -c Release --no-restore
dotnet run --project src/MailTrim.App -c Release --no-build
```

Полная проверка и создание обоих дистрибутивов:

```powershell
./scripts/Check.ps1
./scripts/Publish.ps1
```

ZIP и SHA-256 создаются в `artifacts/`. [Подробные инструкции](docs/DEVELOPMENT.md).
