# MailTrim

[Исходники](https://github.com/lineEdit/MailTrim) · [Релизы](https://github.com/lineEdit/MailTrim/releases) · [Windows CI](https://github.com/lineEdit/MailTrim/actions)

Независимая Windows-оболочка для официальной веб-почты Mail.ru: отдельные ящики, меньше рекламы, контроль над фильтрами. C# / .NET 10 / WPF / Microsoft WebView2. **Версия 0.8.1 — предварительный выпуск.**

MailTrim не связан с Mail.ru или VK, не реализует IMAP/SMTP и не обходит авторизацию или платные почтовые протоколы. Вход, 2FA, письма, поиск и вложения обрабатывает сайт Mail.ru.

## Запуск

1. Windows 10/11 x64. Установите [Microsoft Edge WebView2 Evergreen Runtime](https://developer.microsoft.com/microsoft-edge/webview2/), если его ещё нет.
2. Распакуйте **весь** архив `MailTrim-0.8.1-win-x64.zip` в отдельную папку.
3. Запустите `MailTrim.exe`. В автономном архиве .NET включён; WebView2 Runtime устанавливается отдельно.
4. Войдите в официальную веб-почту. Приложение не запрашивает пароль в собственных формах.
5. Для другого ящика откройте **⋯ → Добавить ящик** рядом со списком профилей сверху и войдите в отдельной сессии.

Дистрибутив пока не подписан Authenticode. Для первоначального входа и проверки реальной почты нужен пользователь; отправка писем и работа с личными данными не автоматизируются тестами.

## Возможности

- Изолированные хранилища WebView2 для профилей; переключение без выхода из других ящиков.
- Блокировка рекламных и аналитических доменов, список исключений, обычные и дополнительные CSS-фильтры.
- JSON-редактор, импорт и перечитывание локального файла правил без пересборки.
- Кнопка временной приостановки фильтров; применение настроек явно перезагружает страницы.
- Светлая, тёмная и системная тема оболочки, передача предпочтения цвета сайту.
- HTTPS-переходы только на явно перечисленные узлы почты и авторизации. Внешние HTTP(S)-ссылки открываются в системном браузере после подтверждения домена.
- Окна авторизации сохраняют профиль и связь с исходным окном. Вложения сохраняются через выбор файла, без автоматического запуска.
- Очистка сессии и удаление локального профиля, без удаления серверного ящика.
- Журнал с кодами событий без содержимого писем и URL.
- Ручная или включаемая пользователем проверка GitHub-релизов выбранного канала. Загрузка и установка официальных обновлений с подтверждением перезапуска.

## Фильтры и ограничения

Начальные правила консервативны. **Полная очистка актуального авторизованного интерфейса Mail.ru не гарантируется:** сайт меняет DOM и рекламные механизмы; встроенные селекторы — стартовый набор, требующий проверки на вашем ящике. Реклама с того же узла, что и нужный контент, может потребовать новых CSS-селекторов. Блокировка не является полной защитой от отслеживания, а WebView2 не предоставляет здесь движок расширения uBlock Origin.

Если что-то сломалось, сохраните черновик и нажмите **Приостановить фильтры**. Затем отключайте сетевые и косметические правила по отдельности. Сайт может проигнорировать предпочтение тёмной темы; в этом случае используйте настройки темы самой почты.

`Настройки → Правила` позволяет импортировать новый JSON, редактировать его и восстановить встроенный набор. Для внешнего редактора файл находится в `%LOCALAPPDATA%\MailTrim\rules.json`; после редактирования нажмите **Прочитать локальный файл**, затем **Сохранить и перезагрузить**. Правила не загружают и не исполняют удалённый JavaScript. Встроенный JS вставляет CSS и обрабатывает метки рекламных карточек в главном документе `https://e.mail.ru`. В версии 0.1.1 добавлены баннеры и рекламные строки; стандартные правила 0.1.0 обновляются автоматически с резервной копией.

Подробности: [формат правил](docs/RULES.md), [модель безопасности](SECURITY.md), [проверка выпуска](docs/TESTING.md).

## Сборка

Требуется [.NET 10 SDK](https://dotnet.microsoft.com/download/dotnet/10.0) на Windows.

```powershell
dotnet restore MailTrim.sln --locked-mode
dotnet build MailTrim.sln -c Release --no-restore
dotnet run --project tests/MailTrim.Tests -c Release --no-build
dotnet run --project src/MailTrim.App -c Release --no-build
```

Автономный дистрибутив:

```powershell
./scripts/Publish.ps1
```

Исходники:

```text
src/MailTrim.Core       Политика URL, формат правил, генератор CSS/JS
src/MailTrim.App        WPF, WebView2, профили, настройки, обновления
tests/MailTrim.Tests    Проверки правил и границ доверия без тестовых пакетов
tests/MailTrim.Smoke    Интеграционные проверки с настоящим WebView2
rules/default.json     Начальный набор блокировки
scripts                Сборка дистрибутива
.github/workflows      Windows CI и публикация релизов
```

## GitHub и релизы

Pipeline запускается автоматически при push в любую ветку, для pull request и тегов `v*`. Его также можно запустить вручную: **Actions → Windows pipeline → Run workflow**. Он восстанавливает фиксированные зависимости, собирает Release, запускает обе группы проверок и упаковывает автономное приложение.

Готовый Windows x64 ZIP с SHA-256 доступен по ссылке в Summary запуска и в **Artifacts → MailTrim-win-x64-build-N**. Артефакты хранятся 30 дней; для скачивания через Actions нужен вход в GitHub. Новая сборка ветки отменяет предыдущую незавершённую сборку этой ветки.

Отправка нового тега `v*` создаёт **draft prerelease**, чтобы проверить артефакты до публичного выпуска. Для следующего выпуска согласуйте `Directory.Build.props`, manifest, подпись версии в интерфейсе и changelog. Перед релизом пройдите ручные проверки. Опубликованные релизы доступны без входа и не зависят от срока хранения Actions-артефактов.

Для проверки обновлений укажите свой `owner/repository` в настройках. С версии 0.8.0 переключатель **Включать предварительные версии** выбирает канал. По умолчанию он включён для текущей серии предварительных выпусков MailTrim: проверяются до 100 последних опубликованных релизов и выбирается наибольший поддерживаемый номер. В стабильном канале используется GitHub `/releases/latest`. Черновики исключены в обоих каналах. Поддерживаются номера вида `v1.2.3` и `v1.2.3.4`; предварительный статус берётся из отметки GitHub. Для официального репозитория доступна установка внутри приложения; для других открывается точная страница выпуска. Проверка при запуске изначально отключена. Подробности установки — ниже.

## Режим «Только важное» (предварительный)

Откройте нужную папку в Mail.ru и нажмите **Только важное**. Слева появится компактный список загруженных писем, справа — текст выбранного письма. Режим не оценивает важность и не прячет рассылки: он убирает оформление сайта. Список берётся из отображённой страницы, а не из почтового API; сохранённые письма доступны также из зашифрованного кэша. «Ещё письма» прокручивает входящие. Для других папок и поиска используйте оригинал.

Картинки в собственном представлении загружаются по отдельному нажатию, без cookies, максимум 8 МБ. Недоступные или требующие авторизации изображения смотрите в оригинале. Официальная страница продолжает работать в фоне и может сама загружать изображения и отмечать выбранное письмо прочитанным. Это не режим полной защиты от пикселей отслеживания.

**Оригинал** возвращает текущую страницу Mail.ru. Кнопка над письмом открывает оригинал для ответа, ссылок и вложений. В первой версии вложения не перечисляются отдельно, форматирование таблиц и сложных HTML-писем упрощено. Авторизация остаётся штатной. Собственное представление строится из текстовых блоков; HTML, сценарии и формы письма не выполняются. Текст прочитанных писем и ссылки на картинки сохраняются в зашифрованном кэше данного профиля. Стандартный кэш исходной страницы WebView2 остаётся отдельным.

При изменении разметки Mail.ru чтение может стать недоступно: в этом случае используйте оригинал. Режим не заменяет полноценный почтовый протокол и пока считается экспериментальным.

## Предварительная загрузка всего ящика

В режиме чтения нажмите **Кэш всего ящика** и подтвердите загрузку. Будут просмотрены стандартные папки (включая спам, корзину и черновики) и пользовательские папки, ссылки на которые найдены на сайте. Сначала собирается список, затем последовательно сохраняются доступные сообщения. Открытие писем сайтом может пометить их прочитанными. Во время загрузки список заблокирован; кнопка **Остановить** и выход из режима прерывают операцию, уже сохранённое остаётся. Повторный запуск дополняет кэш, пропуская сохранённые письма.

Текст, заголовки и ссылки на картинки хранятся в `%LOCALAPPDATA%\MailTrim\ReaderCache\<профиль>` с шифрованием Windows DPAPI CurrentUser и отдельной привязкой к профилю. На диск не пишутся открытые тексты или почтовые URL в именах файлов. После перезапуска режим сразу показывает сохранённый список. Картинки и вложения массово не скачиваются. Ограничение — 512 МБ на профиль; при достижении загрузка останавливается без удаления старого кэша.

Правый клик по **Кэш всего ящика → Удалить зашифрованный кэш** удаляет локальные копии. Очистка сессии и удаление профиля также очищают этот кэш. Удалённые на сервере письма автоматически из локального кэша не исчезают; очистите его для повторного полного чтения. DPAPI не защищает от программ, работающих от имени того же пользователя Windows.

Финальный отчёт показывает число сохранённых писем, ошибки и папки, для которых не удалось подтвердить конец списка. Скрытые папки, нестандартная разметка, медленная подгрузка и ограничения сайта могут помешать полному обходу. Это ускоряющий кэш, а не гарантированная резервная копия ящика; не удаляйте оригиналы на основании результата.


## Работа в Windows

Настройки → **Windows и уведомления**: автозапуск, закрытие в трей и уведомления. Автозапуск по умолчанию выключен; сохраняется в HKCU Run и запускает текущий EXE с `--tray`, без прав администратора. После переноса папки приложения заново сохраните эту настройку.

По умолчанию крестик скрывает окно, сохраняя работу приложения. Значок MailTrim находится рядом с часами (возможно, под стрелкой скрытых значков). Двойной щелчок открывает окно; меню → **Выйти** завершает процесс. Повторный запуск EXE показывает уже работающее окно. При выходе из Windows приложение не препятствует завершению сеанса.

Фоновая проверка входящих выполняется приблизительно каждые две минуты, пока приложение запущено. Используется отдельный WebView2 с той же авторизованной сессией, без открытия писем и без переключения основного окна. Несколько профилей проверяются последовательно; при медленной сети цикл дольше. Первый успешный опрос — исходная точка, старые письма не объявляются новыми. Если прежнее первое письмо исчезло из видимого списка, выполняется новая начальная проверка без уведомления, чтобы не выдавать старые письма за новые. Поэтому это уведомления по доступному списку сайта, а не гарантированная доставка событий или полный счётчик непрочитанного.

Уведомления от обычного опроса содержат только количество, без адресов и текстов. Windows может подавлять их режимом «Не беспокоить». Уведомления можно отключить в настройках или меню трея. Для проверки необходимы сеть, установленный WebView2 и действующий вход в каждом ящике. При закрытом процессе новых уведомлений нет. Изменение настроек Windows не перезагружает почту; изменение фильтров и темы требует перезагрузки с предупреждением.

## Состояние ящиков и непрочитанные (0.5.0)

На вкладках показывается доступный счётчик непрочитанных **во входящих**, а в подсказке и строке состояния — результат проверки и время. Отсутствующий числовой показатель Mail.ru не считается нулём. В трее синий значок с числом (до `99+`) означает известную сумму входящих по всем профилям; серый `M` — подтверждённый ноль либо недоступный счётчик. Подробности видны в подсказке; неизвестные значения на вкладках скрыты. Это не счётчик всех папок. Состояние обновляется после опроса, поэтому может отставать от действий на сайте.

Первая проверка запрашивается через 15 секунд после запуска, последующие — примерно раз в две минуты. В меню трея есть **Проверить почту сейчас**. Проверка статуса работает и при отключённых всплывающих уведомлениях. Неуспешные проверки показывают ошибку или необходимость входа, а не ноль писем. Отсутствие сети определяется по доступности сетевого интерфейса; при недоступности самого сайта показывается ошибка проверки.

При переключении профилей сохраняются выбранное письмо и прокрутка списка/письма. Эти позиции хранятся только на время работы приложения и отдельно для каждого профиля; очистка сессии их удаляет. Сохранённый на диске кэш работает как раньше.

## Уведомления сайта (0.6.0)

В **Настройки → Windows и уведомления** можно выбрать **Использовать уведомления сайта Mail.ru вместо опроса**. Этот режим разрешает WebView2 показывать штатные браузерные уведомления только от `https://e.mail.ru`. Отправитель и тема могут отображаться так, как их передаёт сайт; приложение не копирует их в журнал. По умолчанию остаётся обычная проверка входящих раз в две минуты без текста письма в оповещении.

После включения обновите страницу и откройте вкладку каждого нужного ящика. При необходимости включите уведомления в настройках самого Mail.ru. Оставьте приложение работающим, можно в трее. Получение зависит от сайта, действующей сессии и настроек Windows; для не открывавшихся в этом запуске профилей доставка не гарантируется. Полностью закрытое приложение уведомлений не получает. Уведомления сайта не являются счётчиком непрочитанных.

В режиме сайта оповещения от фонового опроса отключены, но проверка состояния ящиков продолжается. Общий переключатель **Уведомления** в трее отключает оба способа. Если сайт не присылает события, снимите переключатель режима сайта, чтобы вернуться к опросу. Механизм доставки, отключение и разделение режимов проверены на тестовых уведомлениях в WebView2; получение настоящего нового письма требует проверки на вашем ящике.

## Локальный поиск (0.7.0)

В режиме **Только важное** введите текст над списком и нажмите **Enter** или **Найти**. Поиск без учёта регистра проверяет отправителя, тему, превью и сохранённый текст писем текущего профиля. Для полного текста письмо должно быть прочитано и сохранено либо предварительно загружено кнопкой **Кэш всего ящика**. Несохранённые письма из текущего списка ищутся только по доступным метаданным.

Поиск не делает сетевых запросов, не создаёт незашифрованный индекс и выполняется вне потока интерфейса. Он не ищет по содержимому вложений и не гарантирует охват всего серверного ящика. Сброс — кнопка **×**. Обновление списка и запуск загрузки кэша сбрасывают фильтр поиска. Поисковая строка не сохраняется между открытиями режима. На большом кэше поиск может занять некоторое время; закрытие режима отменяет его.

## Положение окна (0.7.1)

Размер, положение и развёрнутое состояние основного окна сохраняются автоматически после изменения и при закрытии в трей. Свёрнутое состояние не становится стартовым: при обычном запуске открывается нормальное либо развёрнутое окно. Автозапуск с параметром --tray по-прежнему скрывает его в трей. Windows переносит полностью оказавшееся за экраном окно на доступный монитор. Координаты хранятся локально в settings.json; отдельное действие пользователя не требуется.

## Удобство чтения (0.8.1)

В режиме **Только важное** перетаскивайте границу между списком и письмом. Ширина списка сохраняется между открытиями и запусками, общая для всех ящиков; двойной щелчок возвращает стандартные 310 точек. Диапазон 260–520 точек оставляет место для чтения. Разделитель также доступен с клавиатуры через Tab и стрелки.

Когда фокус в интерфейсе приложения/режиме чтения: **Ctrl+F** переводит фокус в поиск, **Esc** сбрасывает поиск, **Ctrl+Tab** переключает на следующий ящик, **Ctrl+Shift+Tab** — на предыдущий. В оригинальной веб-странице сочетания может обрабатывать сам Mail.ru/WebView2. Во время загрузки или поиска команды, изменяющие список, могут быть временно недоступны.


### Установка обновлений (с 0.9.0)
В настройках нажмите проверку обновлений, затем «Скачать и установить».
Приложение скачивает ZIP и SHA-256 из официального `lineEdit/MailTrim`, проверяет архив и номер версии. Перед перезапуском сохраните черновики. Загрузка отменяется кнопкой; установка не требует администратора.
Новая версия размещается в `%LOCALAPPDATA%/MailTrim/Updates`, отдельно от профилей и зашифрованного кэша. Предыдущая папка остаётся для возврата. Если новая версия не подтверждает запуск за 60 секунд, запускается предыдущая. Ярлыки на версии начиная с 0.9.0 перенаправляются на установленное обновление; старые версии необходимо один раз заменить вручную. Автозапуск перенастраивается при запуске новой версии.
Контрольная сумма проверяет целостность, но не заменяет цифровую подпись издателя. Автоматическая установка из произвольных репозиториев отключена. Старые пакеты пока сохраняются на диске и не удаляются автоматически.


С версии 0.9.2 pipeline проверяет установку и откат с изолированными процессами: нормальный запуск, сбой, зависание, сбой сразу после готовности, занятая предыдущая версия, неверная версия пакета и несовпадение исходного процесса. После упаковки проверяются SHA-256, распаковка настоящего ZIP и номер сборки. Тесты не открывают личную почту. Эти проверки не подменяют проверку обновления на конкретном пользовательском компьютере.


### Действия из режима чтения
Над выбранным письмом доступны «Ответить», «Прочитано», «В архив» и «Удалить…». Приложение сначала открывает именно выбранное письмо, затем использует однозначно распознанную кнопку панели Mail.ru и оставляет режим чтения открытым. Оригинал для ответа, штатного подтверждения или проверки результата открывается отдельной кнопкой. Оно не отправляет ответы автоматически и не объявляет серверную операцию успешной только по нажатию кнопки. Если разметка сайта отличается, внутри режима появится подсказка для ручного действия. Удаление из корзины и нестандартных папок выполняется только вручную. Зашифрованный кэш не удаляется автоматически после команды: это локальные копии, а не синхронизированное состояние папок.


В 0.10.1 автоматический переход к оригиналу после действия убран. Режим чтения и выбранное письмо остаются на месте; подсказки появляются внутри панели. Для ответа и проверки штатных подтверждений Mail.ru нажмите «Оригинал / вложения ↗» самостоятельно. Встроенного редактора ответа пока нет.


### Ответ рядом со списком (0.11.0)
«Ответить» открывает официальный Mail.ru в правой панели, не выключая «Только важное». Если кнопка ответа на сайте не распознана автоматически, нажмите её в этой панели. Приложение не нажимает «Отправить»: проверьте получателя, текст и вложения и отправьте штатной кнопкой Mail.ru.
Пока панель открыта, выбор другого письма и поиск заблокированы. Можно переключиться на другой ящик и вернуться — в текущем сеансе браузерная страница и введённый текст сохраняются без повторной загрузки. «К чтению» возвращает письмо; перед этим сохраните черновик или отправьте ответ. После завершения приложения восстановление черновиков зависит от сохранения на стороне Mail.ru. Обновление страницы, переход к входящим и выход из приложения могут прервать редактирование.


В 0.11.1 кнопки приложения «Назад», «Обновить», «Входящие» и полный выход предупреждают об открытой панели ответа. Отказ сохраняет страницу и режим; выход учитывает все открытые ящики. Переключение аккаунтов и сворачивание в трей не прерывают редактирование. Проверка не определяет, был ли текст сохранён сервером: сохраните черновик в Mail.ru. Кнопки и сочетания клавиш внутри самой веб-страницы, принудительное завершение процесса и выключение Windows не контролируются этим предупреждением.
